## Jadual dakwaan

| ID | Dakwaan (ayat atomik) | Jenis | Status | Sumber (tahap + rujukan tepat) | Catatan / pembetulan |
|---|---|---|---|---|---|
| F001 | | fakta / petikan / angka / tafsiran / dramatisasi / kapsyen foto | DISAHKAN / DISAHKAN-SEKUNDER / TAFSIRAN / DRAMATISASI / PERLU SEMAKAN / DITOLAK | T1: BT T5 hlm. 103 | |

Peraturan pengisian:
- Satu baris = satu dakwaan atomik (satu tarikh, satu nama, satu angka atau satu petikan).
- `Sumber` mesti cukup tepat untuk orang lain menyemak semula: halaman, nombor dokumen, URL + tarikh akses.
- ID kekal. Jika dakwaan dibuang, tukar status kepada `DITOLAK`; jangan padam baris itu supaya sejarah semakan kekal.
- Dakwaan baharu daripada semakan skrip disambung dengan ID seterusnya dan ditanda `(skrip v2)` dalam catatan.
